# 郎蔚光学项目管理系统

内部项目管理系统 MVP，用于替代繁琐表格维护，聚焦项目管理、项目任务、项目 BOM、采购需求和入库记录。

## 当前范围

- 项目编号手动输入。
- 项目类型仅支持：研发（RD）、销售（SP）。
- 项目负责人统一维护全部数据。
- 采购统计按采购项计算，不按物料数量计算。
- 待交付定义为：已下单未入库。
- 质检仅作为入库记录描述字段。
- 暂不包含账号权限、审批、操作日志、Excel 导入、外部系统集成和 IM 打通。

## 本地运行

直接打开 `index.html`，或使用本地静态服务：

```bash
python3 -m http.server 5173
```

然后访问：

```text
http://localhost:5173
```

## 第一版功能

- 项目管理：项目列表、项目新增、项目编辑、项目删除
- 项目任务：任务分为设计、采购、组装、交付四大类
- 项目BOM：逐条维护 BOM 物料项
- 采购管理：从 BOM 物料项生成采购需求
- 入库记录：作为采购管理的一部分，质检描述仅作为文本记录
- 本地浏览器存储，刷新后保留数据
