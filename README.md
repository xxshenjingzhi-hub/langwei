# 郎蔚光学项目管理系统

内部项目管理系统 MVP，用于替代繁琐表格维护，聚焦项目管理、采购管理、出入库管理和基础下拉选项维护。

## 当前范围

- 项目编号手动输入。
- 项目类型仅支持：研发（RD）、销售（SP）。
- 项目负责人统一维护全部数据。
- 采购统计按采购项计算，不按物料数量计算。
- 待交付定义为：已下单未入库。
- 质检仅作为入库记录描述字段。
- 暂不包含账号权限、审批、操作日志、Excel 导入、外部系统集成和 IM 打通。

## 本地运行方式一：直接打开前端原型

直接打开 `index.html`，或使用本地静态服务：

```bash
python3 -m http.server 5173
```

然后访问：

```text
http://localhost:5173
```

此模式仍使用浏览器 `localStorage` 保存数据。

## 本地运行方式二：启动后端 MVP

当前已提供 Node.js 后端服务，本地默认使用 SQLite：

```bash
npm start
```

然后访问：

```text
http://localhost:5173
```

本地后端数据文件：

```text
backend/data/db.sqlite
```

首次启动时会从 `backend/data/db.json`（存在时优先）或 `backend/data/seed.json` 初始化并导入 SQLite。API 说明见：

前端通过 `http://localhost:5173` 访问时，会自动从 `/api/state` 读取后端数据，并在新增、编辑、删除后同步保存到后端；直接用 `file://` 打开时仍使用浏览器本地存储。

生产部署建议选择 PostgreSQL。部署平台创建 PostgreSQL 后，把连接串配置为 `DATABASE_URL`，后端会自动切换到 PostgreSQL；未配置 `DATABASE_URL` 时继续使用本地 SQLite，便于开发和演示。

```text
docs/backend-api.md
```

数据库表结构草案见：

```text
docs/sql/schema.sql
```

## 第一版功能

- 项目管理：项目列表、项目状态、项目新增、项目编辑、项目删除
- 项目详情：点击项目后查看项目概览、项目任务、项目 BOM、采购记录、入库记录、出库记录
- 项目列表：块状排布，支持全部、进行中、已结束分类
- 采购管理：采购任务列表、项目筛选、采购任务详情
- 入库管理：独立入库记录列表，质检描述仅作为文本记录
- 出库管理：记录项目物料领用、发料和当前库存
- 系统设置：维护项目类型、任务类型、项目状态、采购状态、入库状态、出库状态、供应商名称
- 本地浏览器存储，刷新后保留数据
- 后端 MVP：提供项目、任务、BOM、采购、采购明细、入库、出库的 REST API
